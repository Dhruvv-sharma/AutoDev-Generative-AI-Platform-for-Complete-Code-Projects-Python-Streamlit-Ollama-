# AutoDev-Generative-AI-Platform-for-Complete-Code-Projects-Python-Streamlit-Ollama-
Built an AI-powered project generation platform using Python, Streamlit, and Ollama (Llama 3). Automated code generation, project structuring, README creation, dependency detection via Regex, requirements.txt generation, and ZIP packaging, enabling instant download of complete production-ready projects across multiple languages.


Developed an AI-powered project generation platform using Python, Streamlit, and Ollama (Llama 3) to automate the complete software development lifecycle through an intuitive, chat-based interface. The platform was designed to minimize manual coding effort by enabling users to describe their project requirements in natural language and automatically generate a fully structured software project.

Implemented an intelligent code generation workflow that extracts AI-generated code responses and organizes them into appropriate files and directories based on project requirements. The system supports multiple programming and web development technologies, including Python, HTML, CSS, and JavaScript, allowing users to generate a wide variety of applications from a single interface. Automated file creation and project structuring functionalities ensure that generated projects follow standard development practices and maintain a clean, scalable architecture.

Engineered a robust code extraction mechanism capable of identifying and separating source code blocks from AI responses, ensuring accurate file generation without manual intervention. Additionally, integrated automatic README.md creation and formatting to provide clear project documentation and improve project usability and maintainability.

Designed and implemented an intelligent dependency detection system using Regular Expressions (Regex) to analyze generated source code, identify imported libraries and packages, and automatically generate a requirements.txt file. This feature eliminates the need for developers to manually manage project dependencies and ensures smoother project setup and deployment.

To enhance the overall user experience, developed a seamless project packaging module that automatically compresses the generated project into a downloadable ZIP archive. This enables users to instantly access complete, production-ready project files with proper structure, source code, documentation, and dependency configurations.

The platform significantly streamlines software development by combining AI-powered code generation, automated project organization, dependency management, documentation generation, and project packaging into a single workflow. By reducing repetitive development tasks and simplifying project creation, the solution enables faster prototyping, improved productivity, and efficient generation of deployment-ready software applications.
